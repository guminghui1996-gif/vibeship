# VibeShip

第 1 阶段：最干净的 Next.js App Router + Tailwind 项目骨架。

## 本地运行

```bash
npm run dev
```

打开 http://localhost:3000 查看页面。

## 常用命令

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Vercel 部署

1. 把代码推到 GitHub。
2. 在 Vercel 选择 `Add New...` -> `Project`。
3. 选择 VibeShip 仓库。
4. 保持默认设置，点击 `Deploy`。
